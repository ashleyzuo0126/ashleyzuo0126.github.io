# Ashley Zuo · Portfolio

Bilingual illustrated portfolio featuring AI products, automation and product design.

Live website: https://ashleyzuo0126.github.io/

## Development

```sh
npm ci
npm run dev
```

Build with `npm run build`. GitHub Actions publishes the static `out/` directory to GitHub Pages on pushes to main.

Project copy: `content/projects.ts`. Screenshots, videos and music: `content/media.json` and `public/`.

Some project recordings use clearly labeled local mock services and sample data. They demonstrate product flows, not production AI performance or real business metrics.
