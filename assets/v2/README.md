# 可动画化透明资产 v2

基于原参考图的画风，使用内置 image_gen 独立重新生成。没有裁切原合并图，也没有用 SVG 模拟透明图片。

源 PNG 位于本目录。`sources.json` 记录名称；`scripts/normalize-assets.mjs` 保留 alpha、统一画布，并输出 `public/art/v2/` 的 PNG 与 WebP。角色部件和道具为 512×512，场景层为 1600×1000。锚点使用归一化坐标，见生成的 manifest.json。四肢使用同一独立部件镜像实例化为左右，关节动画由 CSS 控制。

网站使用独立的头、身体、前肢、后肢和尾巴组合小狐狸；站立、行走、思考、工作、庆祝、休息是可交互的骨骼姿态，不是六段预渲染视频。阴影统一由单一地面阴影绘制，避免各部件重复投影。场景使用天空、远景、中景、前景四层，动画遵循系统与网站的减少动效设置。

生成提示词约束：原图只作为画风参考；深棕粗描边、圆润轮廓、橙色与白色小狐狸、左上光源；主体完整、真实透明背景、无文字、无水印、无烘焙投影。每个部件、场景层、道具单独生成。

`public/art/v2/poses/` 额外保存六种关节姿态的静态参考 PNG/WebP（不是逐帧动画文件）；实际网站还会在休息时切换闭眼头部，工作时加入电脑。动画关键帧和关节布局在 `app/rig.css`，角色与道具装配在 `components/Artwork.tsx`。
